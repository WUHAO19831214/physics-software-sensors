# 模板

- `SENSOR_UPGRADE.md`：每次实现、算法、模型或默认配置升级；
- `BENCHMARK_REPORT.md`：一次可复现基准运行；
- `DATASET_CARD.md`：一个版本化数据集；
- `CHANGELOG_ENTRY.md`：面向使用者的升级记录条目。
- `SENSOR_PROPOSAL.md`：新 Sensor 的来源、物理观测边界、复用价值与 ACCEPT/DEFER/REJECT 决策；
- `ADD_SENSOR_PROMPT.md`：以后交给 Codex 的标准新 Sensor 提示词；
- `github-actions-contracts.yml`：授予 GitHub `workflow` 发布权限后，可复制启用的 CI 配置。

复制模板后删除提示性占位符；不要直接改写模板作为某次结果。
