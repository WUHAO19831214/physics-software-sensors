# Screen Capture assets

由 [`examples/web-screen-capture`](../../../examples/web-screen-capture/README.md) 的实际 recorded source 输出生成：

- `captured-screen-frame.png`：明确标注的 synthetic shared-window pixels；
- `frame-packet-metadata.png`：实际 serialized FramePacket；
- `permission-boundary.png`：browser `start()` 权限/结束边界；
- `replay-frame-packet.json`：完整 Schema-valid FramePacket。

它们不是来源项目 UI、真实屏幕共享或设备 SDK 数据。
