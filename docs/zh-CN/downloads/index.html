完整性校验

把 SHA256SUMS 与下载文件放在一起并运行：

shasum -a 256 -c SHA256SUMS

release-manifest.json 记录大小、hash、来源 SHA 和构建环境。完整性一致不等于 Sensor 精度或兼容性已验证。
