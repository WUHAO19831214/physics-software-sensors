# Headless gas teaching replay

Pure Node example, no browser/device needed. Build `npm --prefix packages/gaslab run build`, then run `node examples/headless-gaslab/run.mjs` from the repository root. Output distinguishes external synthetic kPa input, arbitrary-unit simulated wall pressure, input time, simulation elapsed time and pause. Input values are synthetic fixtures, not sensor measurements.
